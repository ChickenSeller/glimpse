# 设置

单击工具栏上的 **设置**，或从托盘菜单选择 **设置...**。单击 **恢复默认值** 可把所有设置恢复为默认。

## 常规

![常规设置](/images/settings-general.png)

| 设置 | 说明 |
| --- | --- |
| 语言 | 界面语言：跟随系统、简体中文、日语或英语 |
| 文件保存位置 | 截图保存在其中的 `Screenshots` 子文件夹，录像保存在 `Recordings` 子文件夹。默认是程序文件夹下的 `output` |
| 清空 | 把已保存的截图、录像或两者移到回收站 |
| 登录时启动 Glimpse | 登录系统时自动启动，只在托盘中待命 |

### 截图

参见[截图相关设置](./capture#截图相关设置)。**滚动截图时显示预览** 和预览的 **不透明度** 参见[滚动截图](./scrolling#拼接预览)。

### 下载

文字识别模型、Firefox 翻译的语言文件和本地翻译模型首次使用时下载。它们的原始地址在 Hugging Face、GitHub 等网站，在部分网络环境下较慢，因此 Glimpse 同时提供镜像。

| 下载来源 | 说明 |
| --- | --- |
| 优先镜像，失败时用官方来源 | 默认 |
| 优先官方来源，失败时用镜像 | |
| 只用官方来源 | 不使用镜像 |

**镜像地址** 默认为 `https://pages.yanlei.org/glimpse-mirror`，可以改为自己搭建的镜像。下载的文件都会校验，与预期不符的文件不会被使用。

### 更新

**启动时** 的检查方式和 **立即检查并更新** 参见[下载与安装](./install#更新)。

**发送匿名使用统计**：发送正在运行的 Glimpse 版本和更新情况，附带本次安装的随机 ID。不会发送任何关于你、你的文件或屏幕的信息。取消勾选即不发送。
