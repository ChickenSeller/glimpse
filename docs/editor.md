# 预览与编辑

## 预览窗口

截图后，图片显示在预览窗口中，状态栏显示图片的像素尺寸。

![预览窗口](/images/editor.png)

| 按钮 | 快捷键 | 作用 |
| --- | --- | --- |
| 另存为... | <kbd>Ctrl</kbd>+<kbd>S</kbd> | 保存为 PNG、JPEG 或 BMP 文件 |
| 保存并复制路径... | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | 保存后把文件的完整路径复制到剪贴板 |
| 复制 | <kbd>Ctrl</kbd>+<kbd>C</kbd> | 把图片复制到剪贴板 |
| 编辑... | <kbd>Ctrl</kbd>+<kbd>E</kbd> | 在标注编辑器中编辑 |
| 贴到屏幕 | <kbd>Ctrl</kbd>+<kbd>P</kbd> | 把图片贴到屏幕上，参见[贴图](./pin) |
| 文字识别和翻译... | <kbd>Ctrl</kbd>+<kbd>T</kbd> | 识别图片中的文字，参见[文字识别与翻译](./ocr) |
| 关闭 | <kbd>Esc</kbd> | 关闭预览窗口 |

保存对话框默认打开设置中所选文件夹下的 `Screenshots` 子文件夹，文件名为 `Glimpse_<日期>_<时间>.png`。

::: tip 保存并复制路径
需要把截图交给只接受文件路径的工具（例如在终端中运行的 AI 编程助手）时，使用 **保存并复制路径**，再把路径粘贴过去即可。
:::

## 标注编辑器

在预览窗口中单击 **编辑...** 打开标注编辑器。

![标注编辑器](/images/annotate.png)

### 标注工具

左侧为标注工具，部分按钮右侧的小箭头可展开同类工具：

| 工具 | 说明 |
| --- | --- |
| 选择 | 选中、移动已画的标注，或修改其属性 |
| 复制 | 复制图片中的一块区域，放到别处 |
| 直线、箭头 | 直线、单箭头、双箭头 |
| 画笔 | 自由画线 |
| 荧光笔 | 自由画、矩形或椭圆的半透明高亮 |
| 文字 | 文字、带指示线的文字、带箭头的文字 |
| 编号 | 自动递增的编号，可带指示线或箭头 |
| 模糊、马赛克 | 遮盖敏感信息 |
| 形状 | 矩形、椭圆、三角形 |
| 贴纸 | 插入图标式贴纸 |

上方的属性栏可修改颜色、线宽、填充方式、阴影、不透明度等。工具的颜色、线宽和字体会保存在设置中，下次继续使用。

### 图像操作

编辑器顶部的工具栏：

| 按钮 | 作用 |
| --- | --- |
| 完成（<kbd>Ctrl</kbd>+<kbd>Enter</kbd>） | 把编辑结果应用到截图并关闭编辑器 |
| 保存、另存为...（<kbd>Ctrl</kbd>+<kbd>S</kbd>） | 保存到文件（编辑已有图片时，**保存** 会覆盖原文件） |
| 复制图像（<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>） | 把编辑后的图片复制到剪贴板 |
| 撤销、重做（<kbd>Ctrl</kbd>+<kbd>Z</kbd>、<kbd>Ctrl</kbd>+<kbd>Y</kbd>） | 撤销或重做上一步 |
| 裁剪 | 裁剪图像 |
| 剪除 | 从图像中剪掉一条水平或垂直的区域，上下或左右两部分自动合拢 |
| 调整大小 | 按像素或百分比缩放图像 |
| 旋转 | 旋转或翻转图像 |
| 画布 | 修改画布大小和颜色，例如在图片周围留白 |

底部可以缩放视图。

## 打开已有图片

以下方式都可以在标注编辑器中打开已有的图片：

- 单击工具栏上的 **打开**，或托盘菜单中的 **打开图片...**；
- 把图片文件拖到工具栏上；
- 在命令行中运行 `glimpse <文件>...`，或在资源管理器中通过“打开方式”选择 `glimpse.exe`。

一次可以打开多个文件。
