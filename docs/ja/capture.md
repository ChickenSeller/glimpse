# 画面のキャプチャ

## ウィンドウと領域

ツールバーの **ウィンドウ** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd> を押します。画面が静止したら、次のように操作します。

- **ウィンドウやコントロールをキャプチャする**：ポインターをウィンドウに合わせると、Glimpse がポインターの下のウィンドウを枠で示し、タイトル、プログラム名、サイズを表示します。クリックするとキャプチャします。マウスホイールで外側のウィンドウと内側のコントロール（ボタン、パネルなど）を切り替えられます。
- **矩形をキャプチャする**：左ボタンを押したままドラッグし、離すとキャプチャします。ドラッグ中に <kbd>Space</kbd> を押し続けると矩形全体を移動できます。

![ウィンドウの選択](/images/ja/capture-window.png)

ポインターの横に、その位置のピクセル座標と矩形のサイズが表示され、正確に位置を合わせられます。

<kbd>Esc</kbd> または右クリックでキャンセルします。

::: info Linux
Linux ではウィンドウを選択できません。矩形をドラッグしてください。[Linux](./linux) を参照してください。
:::

### キャプチャ前の範囲調整

**設定 > 全般** で **範囲を選んだあと、取り込む前に調整する** をオンにすると、矩形を選んでもすぐにはキャプチャせず、調整できる状態になります。

![範囲の調整](/images/ja/capture.png)

| 操作 | 動作 |
| --- | --- |
| 枠やハンドルをドラッグ | 範囲を移動、またはサイズを変更 |
| 矢印キー | 1 ピクセル移動。<kbd>Shift</kbd> を押しながらで 10 ピクセル |
| <kbd>Ctrl</kbd>+矢印キー | サイズを変更 |
| <kbd>Enter</kbd>、または範囲内でダブルクリック | キャプチャ |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 範囲をクリップボードにコピーして終了 |
| 右クリック | 範囲を破棄して選び直す |

この設定はピン留め、文字認識、QR コードの読み取りにも適用されます。

## フリーハンド領域

ツールバーの **フリーハンド** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>6</kbd> を押します。ボタンを押したままキャプチャしたい部分を囲み、離すとキャプチャします。

輪郭の外側は既定で透明になります（PNG で保存すると透明のまま残ります）。**設定 > 全般** の **フリーハンド領域の外側** で **透明** をオフにすると、指定した色で塗りつぶします。

## 全画面

<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>3</kbd> で画面全体をキャプチャします。複数のディスプレイがある場合は、すべてのディスプレイを合わせたデスクトップ全体をキャプチャします。

ツールバーの **全画面をキャプチャ** ボタンは既定で非表示です。**設定 > ツールバー** で表示できます。

## 遅延キャプチャ

メニューやツールチップなど、マウスを動かすと消えてしまうものをキャプチャするには、遅延キャプチャを使います。

1. ツールバーの **キャプチャ前の遅延** をクリックし、1、2、3、5、10 秒または **カスタム...** を選びます。
2. キャプチャを開始します。カウントダウンが表示されている間に、目的のメニューを開きます。
3. カウントダウンが終わると画面が静止するので、範囲を選びます。

カウントダウン中にクリックするか <kbd>Esc</kbd> を押すとキャンセルします。遅延の設定は保持されるので、不要になったら **遅延なし** を選んでください。

## キャプチャのあと

キャプチャした画像はプレビューウィンドウに表示され、保存、コピー、編集、ピン留め、文字認識を行えます。[プレビューとエディター](./editor)を参照してください。

**設定 > 全般** で **キャプチャをクリップボードにもコピーする** をオンにすると、キャプチャのたびにクリップボードにもコピーします。

## キャプチャ関連の設定

**設定 > 全般 > キャプチャ** の項目：

| 設定 | 説明 |
| --- | --- |
| Glimpse のツールバーを含める | キャプチャ時にツールバーを隠さない |
| マウスポインターを含める | キャプチャにポインターを残す（Windows のみ） |
| キャプチャをクリップボードにもコピーする | キャプチャのたびにコピー |
| フリーハンド領域の外側 | 透明、または指定した色 |
| 範囲を選んだあと、取り込む前に調整する | [キャプチャ前の範囲調整](#キャプチャ前の範囲調整)を参照 |
