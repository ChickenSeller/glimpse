# ダウンロードとインストール

## ダウンロード

各バージョンは次の場所からダウンロードできます。内容は同じです。

- このサイトの[リリースページ](https://pages.yanlei.org/kaguya/glimpse/releases.html)
- [GitHub](https://github.com/ChickenSeller/glimpse/releases)

| ファイル | 対象 |
| --- | --- |
| `Glimpse-<バージョン>-windows-x64.zip` | Windows 10、11（x64） |
| `glimpse_<バージョン>_amd64.deb` | Debian、Ubuntu など |
| `glimpse-<バージョン>-1.x86_64.rpm` | Fedora、RHEL など |

## Windows

Glimpse はポータブル版で、インストールは不要です。

1. アーカイブを任意のフォルダー（例：`C:\Tools\Glimpse`）に展開します。
2. その中の `glimpse.exe` を実行します。

Windows へのサインイン時に起動するには、**設定 > 全般** で **サインイン時に Glimpse を起動する** をオンにします。この場合、Glimpse はツールバーを表示せず通知領域で待機します。

::: tip 書き込めるフォルダーに置く
Glimpse は設定をプログラムフォルダーの `config.ini` に保存し、キャプチャと録画も既定ではプログラムフォルダーの `output` サブフォルダーに保存します。`C:\Program Files` など、書き込みに管理者権限が必要な場所には展開しないでください。
:::

## Linux

パッケージをインストールします。例：

```sh
sudo apt install ./glimpse_<バージョン>_amd64.deb     # Debian、Ubuntu
sudo dnf install ./glimpse-<バージョン>-1.x86_64.rpm  # Fedora、RHEL
```

Glimpse は `/opt/glimpse` にインストールされ、メニュー項目と `glimpse` コマンドが追加されます。Linux での違いは [Linux](./linux) を参照してください。

## 更新

Windows 版は起動時に新しいバージョンを確認します。動作は **設定 > 全般 > 更新** で選択します。

| 項目 | 説明 |
| --- | --- |
| 更新の前に毎回確認する | 新しいバージョンがあると更新するか確認します（既定） |
| 自動的に更新する | 新しいバージョンを自動でダウンロード・検証・インストールし、Glimpse を再起動します |
| 必須の更新を自動的に行う | 必須とされたバージョンのみ自動でインストールし、それ以外は確認します |
| 更新しない | 起動時に確認しません |

**今すぐ確認して更新** でいつでも確認できます。Linux 版は新しいバージョンを通知するので、リリースページから新しいパッケージをダウンロードしてください。

## 設定ファイル

| 状況 | 場所 |
| --- | --- |
| プログラムフォルダーに書き込める（Windows のアーカイブ版） | プログラムフォルダーの `config.ini` |
| 書き込めない（Linux のパッケージなど） | Windows：レジストリ、Linux：`~/.config/Glimpse/Glimpse.conf` |

`config.ini` はプログラムフォルダーと一緒に移動します。フォルダーごとコピーすれば、設定（エディターのツールの色、太さ、フォントを含む）を別のコンピューターに持っていけます。

認識・翻訳モデルはプログラムフォルダーではなくユーザーのデータフォルダーに保存されるため、Glimpse を更新・移動しても再ダウンロードは不要です。

## 削除

- Windows：Glimpse を終了し（トレイメニュー > **終了**）、プログラムフォルダーを削除します。サインイン時の起動を有効にしている場合は、先に設定でオフにしてください。
- Linux：パッケージマネージャーで削除します。例：`sudo apt remove glimpse`。
