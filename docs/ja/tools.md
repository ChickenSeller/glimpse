# QR コード、十字線、定規

## QR コード

ツールバーの **QR コード** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>4</kbd> を押して、QR コードやバーコードを含む範囲を選びます。スマートフォンは不要です。

**QR コードを読み取る** ウィンドウに、見つかったすべてのコードと種類が表示されます。項目を選んで内容を **コピー** するか、内容が URL なら **リンクを開く** をクリックします。

## クロスヘアと色の取得

ツールバーの **クロスヘア** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>8</kbd> を押します。画面全体に十字線が表示され、横の拡大鏡にポインターの下のピクセルの色（HEX と RGB）と座標が表示されます。

![クロスヘア](/images/ja/crosshair.png)

### 距離を測る

クリックで点を固定してからポインターを動かすと、2 点間の水平・垂直距離と直線距離が表示され、画面上にも 2 点を結ぶ線が引かれます。右クリックで固定を解除します。

### 色を取得する

色を取得したいピクセルをダブルクリックすると **画面の色** ウィンドウが開き、HEX、RGB、HSL 形式の値をそれぞれコピーできます。**もう一度取得** でクロスヘアに戻ります。

![画面の色](/images/ja/color.png)

### キー操作

| キー | 動作 |
| --- | --- |
| 矢印キー | 十字線を 1 ピクセル移動 |
| <kbd>Space</kbd> | 現在の位置に固定 |
| <kbd>Enter</kbd> | 現在のピクセルの色を取得 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 位置をコピー |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | 色をコピー |
| <kbd>Esc</kbd> | 終了 |

## スクリーンルーラー

ツールバーの **ルーラー** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>7</kbd> を押します。水平と垂直の 2 本の定規が十字に交わって最前面に半透明で表示され、交点からポインターまでの距離を方向ごとにピクセル単位で示します。

| 操作 | 動作 |
| --- | --- |
| 定規をドラッグ | 移動 |
| 定規の端をドラッグ | その方向の長さを変更 |
| 矢印キー | 移動 |
| <kbd>Ctrl</kbd>+矢印キー | 長さを変更 |
| <kbd>Ctrl</kbd>+ホイール | 不透明度を変更 |
| <kbd>Ctrl</kbd> を押し続ける | 交点とポインターを結ぶ線と x 軸・y 軸の角度を表示 |

右クリックメニューで角度の表示を **度数法** または **弧度法** に切り替えたり、定規を **閉じる** ことができます。定規の位置と長さは保存され、次回も同じ状態で開きます。
