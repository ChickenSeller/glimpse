# よくある質問

## ホットキーが効かない

ほかのプログラムがそのホットキーを使っている可能性があります。Glimpse は起動時に使えないホットキーをトレイで通知し、**設定 > ホットキー** でも該当する項目に表示します。別の組み合わせを選んでください。[ホットキーの変更](./toolbar#ホットキーの変更)を参照してください。

## ツールバーが見当たらない

トレイに最小化されているか、画面の端にドッキングして細い帯になっている可能性があります。トレイの Glimpse アイコンをクリックすると表示されます。ドッキングしている場合は、画面端の帯にポインターを合わせると展開します。

## メニューやツールチップがキャプチャすると消えてしまう

[遅延キャプチャ](./capture#遅延キャプチャ)を使います。遅延の秒数を設定し、キャプチャを開始してからカウントダウン中にメニューを開いてください。

## モデルのダウンロードが遅い、または失敗する

**設定 > 全般 > ダウンロード** でダウンロード元を切り替えるか、ダウンロードウィンドウでリンクをコピーし、ブラウザーやダウンロードツールでダウンロードしてからファイルを選んでください。[モデルのダウンロード](./ocr#モデルのダウンロード)を参照してください。

## Windows OCR で使える言語がないと表示される

Windows にその言語の光学式文字認識機能が必要です。[認識エンジン](./ocr#認識エンジン)を参照してください。PaddleOCR を使う方法もあります。

## 認識結果が正確でない

- **設定 > 文字認識** で必要な言語だけを選んでください。
- 中国語と日本語には PaddleOCR を使ってください。
- 文字が小さすぎる場合は、ページを拡大してからキャプチャしてください。

## 翻訳画像で改行を保つよう表示される

翻訳画像を作るには、認識した文字が段落ごとに 1 行のままである必要があります。編集で段落を結合・分割した場合は、改行を元に戻して翻訳し直してください。[翻訳画像](./ocr#翻訳画像)を参照してください。

## Ollama でタイムアウトする

モデルの初回の読み込みには時間がかかります。大きなモデルやグラフィックカードがない場合は特にそうです。少し待ってから再試行するか、小さいモデルを使ってください。[Ollama を使う](./translation#ollama-を使う)を参照してください。

## プロンプトボタンがない

**プロンプト** ボタンは、プロンプトを変更できるエンジンでのみ表示されます。Hy-MT2 や Index-Translate などの翻訳専用モデルは組み込みのプロンプトを使うため、表示されません。[プロンプト](./translation#プロンプト)を参照してください。

## スクロールキャプチャがずれる

スクロールキャプチャはまだ試験的な機能です。次の方法を試してください。

- <kbd>Ctrl</kbd>+<kbd>Z</kbd> で最後の部分を取り消し、ゆっくりスクロールし直す
- 範囲を選ぶときに <kbd>Ctrl</kbd> を押して、自分でスクロールする
- スクロールする部分だけを範囲にし、固定されたヘッダーやサイドバーを含めない

[スクロールキャプチャ](./scrolling)を参照してください。

## 設定の保存場所と移行方法

[設定ファイル](./install#設定ファイル)を参照してください。プログラムフォルダーごとコピーすれば、設定も一緒に移行できます。
