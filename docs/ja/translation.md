# 翻訳エンジンとプロンプト

翻訳エンジンは **設定 > 翻訳** で選びます。文字認識・翻訳ウィンドウでは、1 回の翻訳だけ別のエンジンに切り替えることもできます。

![翻訳の設定](/images/ja/settings-translation.png)

## エンジン一覧

| エンジン | ネット接続 | キー | 特徴 |
| --- | --- | --- | --- |
| Firefox 翻訳（既定） | 不要 | 不要 | 高速でモデルが小さく、どのコンピューターでも動作 |
| ローカルモデル（llama.cpp） | 不要 | 不要 | 大規模言語モデルをこのコンピューターで実行。グラフィックカードがあると高速 |
| Google 翻訳（無料） | 必要 | 不要 | 高品質で多言語に対応。非公式のため制限される場合あり |
| bilibili Index-Translate（無料） | 必要 | 不要 | 翻訳用の大規模モデル。自然な訳文で 150 言語に対応。やや低速 |
| DeepL | 必要 | 必要 | 自然な訳文。特にヨーロッパ言語と日本語に強い。無料版は月 50 万文字 |
| Google Cloud 翻訳 | 必要 | 必要 | 多言語、高速 |
| Microsoft 翻訳 | 必要 | 必要 | 多言語。無料枠は月 200 万文字 |
| Claude | 必要 | 必要 | 大規模言語モデル。認識の誤りを読み取り、語調や用語を保つ。従量課金 |
| OpenAI 互換 API | サービスによる | サービスによる | DeepSeek、Qwen などのオンラインサービス、またはローカルの Ollama、LM Studio |

翻訳先：簡体字中国語、繁体字中国語、日本語、英語、韓国語、フランス語、ドイツ語、スペイン語、ロシア語。原文の言語は自動で判定されます。

::: info プライバシー
オフラインのエンジンでは、文字がこのコンピューターの外に出ることはありません。オンラインのエンジンでは、このコンピューターで認識した文字を選んだサービスに送信して翻訳します。キャプチャ画像そのものは送信しません。API キーはこのコンピューターのユーザー設定に保存されます。
:::

## Firefox 翻訳

Firefox のオフライン翻訳で使われているエンジン（Bergamot）です。言語の組み合わせごとに、初回に 35～70 MB の言語ファイルをダウンロードします。英語と他の言語の間を翻訳し、それ以外の組み合わせ（中国語と日本語など）は英語を経由します。

現在は Windows 版のみで利用できます。

## ローカルモデル

llama.cpp で言語モデルをこのコンピューター上で実行します。グラフィックカードがあれば Vulkan で GPU を使い、なければ CPU を使います。**モデル** で選択します。

| モデル | サイズ | 説明 |
| --- | --- | --- |
| Hy-MT2 1.8B（既定） | 1.1 GB | 軽量。一般的なノート PC でも動作 |
| Hy-MT2 7B | 4.6 GB | 最高品質。グラフィックカード推奨 |
| Index-Translate 2B | 1.3 GB | bilibili 製、軽量 |
| Index-Translate 9B | 5.8 GB | bilibili 製。グラフィックカード推奨 |
| Qwen3 4B | 2.5 GB | 汎用モデル。プロンプトを変更可能 |

選んだモデルは初回使用時にダウンロードされます。**その他の GGUF モデル ファイル...** で、自分でダウンロードした GGUF 形式のモデルも使えます。

モデルは翻訳時に読み込まれ、その後 5 分間メモリ（または VRAM）に残るため、その間の翻訳では読み込み直しが不要です。

## OpenAI 互換 API

OpenAI のチャット API（`/chat/completions`）を提供する任意の言語モデルサービスに使います。

| 項目 | 説明 |
| --- | --- |
| API アドレス | `/v1` を含むアドレス。例：`https://api.deepseek.com/v1` |
| モデル名 | 例：`deepseek-chat` |
| API キー | オンラインサービスのキー。このコンピューター上のサーバーには通常不要 |

### Ollama を使う

1. [Ollama](https://ollama.com/) をインストールし、モデルを取得します。例：`ollama pull qwen3:8b`。
2. **設定 > 翻訳** で **OpenAI 互換 API** を選びます。
3. **API アドレス** に `http://localhost:11434/v1`、**モデル名** に `qwen3:8b` を入力し、**API キー** は空欄のままにします。

このコンピューター上のサーバーに対しては、待ち行列でタイムアウトしないよう、Glimpse は段落を 1 つずつ送信します。Ollama ではモデルの「思考」も無効にして高速化します。モデルの初回の読み込みには時間がかかることがあります。タイムアウトした場合は、少し待ってから再試行してください。

LM Studio などほかのローカルサーバーも同じ方法で設定します。アドレスは各ソフトウェアの説明を参照してください（LM Studio の既定は `http://localhost:1234/v1`）。

## プロンプト

大規模言語モデル系のエンジンでは、プロンプトを変更して訳文の文体、用語、形式を指定できます。

| エンジン | プロンプトの変更 |
| --- | --- |
| Claude | 可能。返答の形式（段落の JSON 配列）は Glimpse がプロンプトとは別に付け加えます |
| OpenAI 互換 API | 可能 |
| ローカルモデル：Qwen3 4B とその他の汎用 GGUF モデル | 可能 |
| ローカルモデル：Hy-MT2、Index-Translate | 不可。学習時の組み込みプロンプトを使用 |
| bilibili Index-Translate（オンライン） | 不可。固定のプロンプトを使用 |
| Firefox、Google、DeepL、Microsoft | 対象外（従来型の機械翻訳で、プロンプトはありません） |

ファイル名に `hy-mt`、`hunyuan-mt`、`index-translate` を含む GGUF ファイルは翻訳専用モデルとみなされ、同じく組み込みのプロンプトを使います。

### 既定のプロンプト

**設定 > 翻訳** の **既定のプロンプト** で変更し、**既定に戻す** で元に戻します。`{language}` は翻訳先の言語を表し、翻訳時に言語名に置き換えられます。プロンプトに `{language}` がない場合は、Glimpse が末尾に翻訳先の言語を書き加えます。

既定のプロンプトは次のとおりです。

```
Translate the text into {language}. It was recognized from a screenshot and may contain OCR mistakes; read through them. Keep the meaning, tone, numbers, names and line breaks. Reply with the translation only, without notes or quotes.
```

（Claude の既定のプロンプトには最後の 1 文がありません。返答の形式は Glimpse が別に付け加えます。）

### 1 回の翻訳だけのプロンプト

文字認識・翻訳ウィンドウで **プロンプト** をクリックすると、そのウィンドウだけのプロンプトに変更できます。設定の既定値は変わりません。**既定に戻す** で設定の既定のプロンプトに戻ります。
