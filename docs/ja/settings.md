# 設定

ツールバーの **設定** をクリックするか、トレイメニューで **設定...** を選びます。**デフォルトに戻す** ですべての設定を既定値に戻せます。

## 全般

![全般の設定](/images/ja/settings-general.png)

| 設定 | 説明 |
| --- | --- |
| 言語 | 表示言語：システムの既定、日本語、英語、簡体字中国語 |
| 保存先フォルダー | スクリーンショットはその中の `Screenshots`、録画は `Recordings` サブフォルダーに保存。既定はプログラムフォルダーの `output` |
| クリア | 保存したスクリーンショット、録画、またはその両方をごみ箱に移動 |
| サインイン時に Glimpse を起動する | サインイン時に起動し、トレイで待機 |

### キャプチャ

[キャプチャ関連の設定](./capture#キャプチャ関連の設定)を参照してください。**スクロールキャプチャ中にプレビューを表示** とその **不透明度** は[スクロールキャプチャ](./scrolling#プレビュー)を参照してください。

### ダウンロード

認識モデル、Firefox 翻訳の言語ファイル、ローカル翻訳モデルは、初めて必要になったときにダウンロードされます。これらは Hugging Face や GitHub などにあり、ネットワーク環境によっては遅いため、Glimpse はミラーも用意しています。

| ダウンロード元 | 説明 |
| --- | --- |
| ミラーを優先し、失敗したら公式 | 既定 |
| 公式を優先し、失敗したらミラー | |
| 公式のみ | ミラーを使わない |

**ミラー** の既定は `https://pages.yanlei.org/glimpse-mirror` で、自分で用意したミラーに変更できます。ダウンロードしたファイルはすべて検証され、想定と異なるファイルは使われません。

### 更新

**起動時** の動作と **今すぐ確認して更新** については[ダウンロードとインストール](./install#更新)を参照してください。

**匿名の使用統計を送信する**：実行中の Glimpse のバージョンと更新の状況を、このインストールのランダムな ID とともに送信します。あなた自身、ファイル、画面に関する情報は一切送信しません。オフにすると何も送信しません。
