# 文字認識と翻訳

## 文字を認識する

1. ツールバーの **テキスト** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>5</kbd> を押して、文字を含む範囲を選びます。プレビューウィンドウの **文字認識・翻訳...** でも同じことができます。
2. **文字認識・翻訳** ウィンドウが開きます。上部にキャプチャした画像が表示され、認識した各行が枠で示されます。
3. 認識した文字は中央のテキスト欄に、1 行に 1 段落ずつ表示されます。直接修正してから **コピー** をクリックできます。

![文字認識・翻訳ウィンドウ](/images/ja/ocr.png)

**認識エンジン** で、このウィンドウだけ別のエンジンで認識し直せます。ウィンドウを開いたときのエンジンは **設定 > 文字認識** で指定します。

## 翻訳する

1. **翻訳先** で言語を選びます。原文の言語は自動で判定されます。
2. **エンジン** で翻訳エンジンまたはローカルモデルを選びます。ウィンドウを開いたときのエンジンは **設定 > 翻訳** で指定します。
3. **翻訳** をクリックします。下に訳文が表示されます。修正してから **訳文をコピー** をクリックできます。

認識した文字を修正してから翻訳すると、訳文は修正後の改行や空行に従います。

大規模言語モデル系のエンジン（Claude、OpenAI 互換 API、ローカルの汎用モデル）では **プロンプト** ボタンが表示され、このウィンドウだけプロンプトを変更できます。[翻訳エンジンとプロンプト](./translation#プロンプト)を参照してください。

## 翻訳画像

**翻訳画像** をクリックすると、キャプチャの元の文字の位置に訳文を描いた画像が作成され、プレビューウィンドウで開きます。保存、コピー、編集を続けて行えます。

<div class="compare">

![元の画像](/images/ja/original.png)

![翻訳画像](/images/ja/translated.png)

</div>

Glimpse は元の文字を消して周囲の背景で埋め、元の文字の色、大きさ、太さ、揃え方に合わせて訳文を配置します。単色やグラデーションの背景で最もきれいに仕上がります。模様や写真の背景は完全には復元できません。

::: tip
翻訳画像を作るには、テキスト欄が「認識した段落ごとに 1 行」のままである必要があります。段落を手動で結合・分割した場合は、改行を元に戻して翻訳し直すよう表示されます。
:::

## 認識エンジン

| エンジン | 特徴 | 初回使用時 |
| --- | --- | --- |
| PaddleOCR（既定） | 最も正確で、特に中国語と日本語に強い。1 つのモデルで対応言語すべてを認識 | 約 31 MB のモデルをダウンロード |
| Windows OCR | Windows に組み込み、ダウンロード不要。一度に 1 言語のみ | Windows にその言語の光学式文字認識機能が必要 |
| Tesseract | 定番のオープンソースエンジン | 言語ごとに 2～4 MB をダウンロード |

Windows OCR は、選択した言語のうち OCR 機能がインストールされている最初の言語を使います。使える言語がないと表示された場合は、Windows の **設定 > 時刻と言語 > 言語** でその言語を追加し、「光学式文字認識」機能をインストールしてください。

### 認識する言語

**設定 > 文字認識** で認識する言語（文字）を選びます：簡体字中国語、繁体字中国語、英語、日本語、フランス語。選ぶ言語が少ないほど、認識が速く正確になります。

![文字認識の設定](/images/ja/settings-ocr.png)

## モデルのダウンロード

認識モデルとオフライン翻訳の言語ファイルはプログラムに含まれていません。初めて必要になったとき、Glimpse がダウンロードするファイルを一覧表示して確認します。ダウンロード後はオフラインで使えます。

ダウンロードが遅い場合：

- **公式リンクをコピー** または **ミラーのリンクをコピー** で、ブラウザーやダウンロードツールでダウンロードし、**ファイルを選択...** でダウンロードしたファイルを選びます（複数をまとめて選べます。Glimpse がファイル名で対応付けます）。
- **設定 > 全般 > ダウンロード** でダウンロード元を変更します。[設定](./settings#ダウンロード)を参照してください。

ダウンロードは途中でキャンセルでき、ほかの方法に切り替えられます。
