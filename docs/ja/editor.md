# プレビューとエディター

## プレビューウィンドウ

キャプチャした画像はプレビューウィンドウに表示され、ステータスバーに画像のピクセルサイズが表示されます。

![プレビューウィンドウ](/images/ja/editor.png)

| ボタン | ショートカット | 動作 |
| --- | --- | --- |
| 名前を付けて保存... | <kbd>Ctrl</kbd>+<kbd>S</kbd> | PNG、JPEG、BMP で保存 |
| 保存してパスをコピー... | <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>S</kbd> | 保存後、ファイルのフルパスをクリップボードにコピー |
| コピー | <kbd>Ctrl</kbd>+<kbd>C</kbd> | 画像をクリップボードにコピー |
| 編集... | <kbd>Ctrl</kbd>+<kbd>E</kbd> | 注釈エディターで編集 |
| 画面にピン留め | <kbd>Ctrl</kbd>+<kbd>P</kbd> | 画像を画面に貼り付け。[画面に貼り付け](./pin)を参照 |
| 文字認識・翻訳... | <kbd>Ctrl</kbd>+<kbd>T</kbd> | 画像内の文字を認識。[文字認識と翻訳](./ocr)を参照 |
| 閉じる | <kbd>Esc</kbd> | プレビューを閉じる |

保存ダイアログは、設定で選んだフォルダーの `Screenshots` サブフォルダーで開き、ファイル名は `Glimpse_<日付>_<時刻>.png` になります。

::: tip 保存してパスをコピー
ファイルのパスしか受け付けないツール（ターミナルで動く AI コーディングアシスタントなど）にキャプチャを渡すときは、**保存してパスをコピー** を使い、パスを貼り付けます。
:::

## 注釈エディター

プレビューウィンドウで **編集...** をクリックすると注釈エディターが開きます。

![注釈エディター](/images/ja/annotate.png)

### 注釈ツール

左側に注釈ツールがあります。一部のボタンの横の小さな矢印で、同じ種類のツールを選べます。

| ツール | 説明 |
| --- | --- |
| 選択 | 描いた注釈を選択・移動し、属性を変更 |
| 複製 | 画像の一部をコピーして別の場所に置く |
| 直線、矢印 | 直線、矢印、両端矢印 |
| ペン | 自由な線 |
| マーカー | 半透明のハイライト（自由線、四角形、楕円） |
| テキスト | テキスト、引き出し線付き、矢印付き |
| 番号 | 自動で増える番号。引き出し線や矢印付きも可能 |
| ぼかし、モザイク | 見せたくない情報を隠す |
| 図形 | 四角形、楕円、三角形 |
| ステッカー | アイコン風のステッカーを挿入 |

上のバーで色、線の太さ、塗りつぶし、影、不透明度などを変更できます。各ツールの色、太さ、フォントは設定に保存され、次回も引き継がれます。

### 画像の操作

エディター上部のツールバー：

| ボタン | 動作 |
| --- | --- |
| 完了（<kbd>Ctrl</kbd>+<kbd>Enter</kbd>） | 編集内容をキャプチャに反映してエディターを閉じる |
| 保存、名前を付けて保存...（<kbd>Ctrl</kbd>+<kbd>S</kbd>） | ファイルに保存（既存の画像を開いた場合、**保存** は元のファイルを上書き） |
| 画像をコピー（<kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd>） | 編集後の画像をクリップボードにコピー |
| 元に戻す、やり直し（<kbd>Ctrl</kbd>+<kbd>Z</kbd>、<kbd>Ctrl</kbd>+<kbd>Y</kbd>） | 直前の操作を取り消し、またはやり直し |
| トリミング | 画像をトリミング |
| 切り取り | 画像から水平または垂直の帯状領域を切り取り、両側を詰める |
| サイズ変更 | ピクセルまたはパーセントで拡大・縮小 |
| 回転 | 画像を回転または反転 |
| キャンバス | キャンバスのサイズと色を変更（画像の周りに余白を付けるなど） |

下部で表示を拡大・縮小できます。

## 既存の画像を開く

次のいずれかの方法で、既存の画像を注釈エディターで開けます。

- ツールバーの **開く**、またはトレイメニューの **画像を開く...**
- 画像ファイルをツールバーにドロップ
- コマンドラインで `glimpse <ファイル>...` を実行、またはエクスプローラーの「プログラムから開く」で `glimpse.exe` を選択

複数のファイルを一度に開けます。
