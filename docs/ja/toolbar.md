# ツールバー、トレイ、ショートカットキー

## ツールバー

![ツールバー](/images/ja/toolbar.png)

ツールバーのボタンは左から次のとおりです。

| ボタン | 機能 | 参照 |
| --- | --- | --- |
| ドラッグハンドル | ドラッグしてツールバーを移動 | |
| ウィンドウ | ウィンドウやコントロールをクリック、または矩形をドラッグしてキャプチャ | [画面のキャプチャ](./capture) |
| スクロール | スクロールキャプチャ（Windows、試験的） | [スクロールキャプチャ](./scrolling) |
| フリーハンド | 任意の輪郭でキャプチャ | [画面のキャプチャ](./capture#フリーハンド領域) |
| ピン留め | 領域をキャプチャして画面にピン留め | [画面に貼り付け](./pin) |
| 録画 | 画面を録画。もう一度押すと停止 | [画面録画](./record) |
| QR コード | 領域内の QR コードやバーコードを読み取る | [QR コード](./tools#qr-コード) |
| テキスト | 領域内の文字を認識してコピーまたは翻訳 | [文字認識と翻訳](./ocr) |
| クロスヘア | 位置・色・距離を表示する全画面の十字線 | [クロスヘアと色の取得](./tools#クロスヘアと色の取得) |
| ルーラー | ピクセル単位のスクリーンルーラー | [スクリーンルーラー](./tools#スクリーンルーラー) |
| ペン | 画面に描画 | [スクリーンホワイトボード](./whiteboard) |
| キャプチャ前の遅延 | キャプチャ前に待つ秒数 | [画面のキャプチャ](./capture#遅延キャプチャ) |
| 開く | 画像を開いて編集 | [プレビューとエディター](./editor#既存の画像を開く) |
| 設定 | 設定ウィンドウを開く | [設定](./settings) |
| トレイに最小化 | ツールバーを隠す。トレイアイコンやホットキーで再表示 | |

**全画面をキャプチャ** ボタンは既定で非表示です。設定で表示できます。

### 画面端へのドッキング

ツールバーを画面の端までドラッグして離すと、その端にドッキングします。普段は細い帯に縮み、ポインターを合わせると展開します。端から離すとドッキングを解除します。

### 画像を開く

画像ファイルをツールバーにドロップすると、エディターで開きます。

### カスタマイズ

**設定 > ツールバー** で次の操作ができます。

- チェックを外すとボタンを非表示にします。項目のドラッグや **上へ**・**下へ** で順序を変更します。
- **ツールバーのサイズ** でボタンの大きさを変更します。

## トレイアイコン

通知領域の Glimpse アイコンをクリックするとツールバーを表示します。右クリックメニューには各キャプチャ機能のほか、次の項目があります。

- **画像を開く...**
- **すべてのピン留めを閉じる**
- **ツールバーを表示**
- **設定...**
- **Glimpse について...**
- **終了**

## ホットキー

ホットキーはどのプログラムを使用中でも有効です（グローバルホットキー）。

| ホットキー | 機能 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd> | ウィンドウ／領域をキャプチャ |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>2</kbd> | スクリーンペン（開いているとき：クリックスルーの切り替え） |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>3</kbd> | 全画面をキャプチャ |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | 画面にピン留め |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>4</kbd> | QR コードを読み取る |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>5</kbd> | 文字認識・翻訳 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>6</kbd> | フリーハンド領域をキャプチャ |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>7</kbd> | スクリーンルーラー |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>8</kbd> | クロスヘア／色の取得 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>9</kbd> | スクロールキャプチャ（試験的） |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> | 画面を録画（もう一度押すと停止） |

### ホットキーの変更

1. **設定 > ホットキー** を開きます。
2. 項目の入力欄をクリックし、新しいキーの組み合わせを押します。入力欄を空にするとそのホットキーは無効になります。
3. **OK** をクリックします。

設定ウィンドウを開いている間、ホットキーは一時停止します。

他のプログラムが既に使用しているホットキーは、Glimpse の起動時にトレイで通知され、設定でも「他のプログラムが使用中」と表示されます。別の組み合わせを選んでください。
