# 画面に貼り付け

ピン留めは、キャプチャした領域を小さなウィンドウとしてすべてのウィンドウの前面に固定します。資料を見ながらの作業、数値の一時的なメモ、2 つの版の比較などに便利です。

![ピン留め](/images/ja/pin.png)

## ピン留めする

- ツールバーの **ピン留め** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> を押して範囲を選びます。ピンはキャプチャした元の位置に表示され、画面のその部分が静止したように見えます。
- プレビューウィンドウで **画面にピン留め**（<kbd>Ctrl</kbd>+<kbd>P</kbd>）をクリックすると、キャプチャした画像をピン留めします。

複数の画像を同時にピン留めできます。

## 操作

| 操作 | 動作 |
| --- | --- |
| ドラッグ | ピンを移動 |
| マウスホイール | ポインターの位置を中心に拡大・縮小 |
| <kbd>Ctrl</kbd>+ホイール | 不透明度を変更 |
| ダブルクリック、または右上の閉じるボタン | このピンを閉じる |

ポインターをピンに合わせると、操作のヒントが短時間表示されます。

右クリックメニュー：

- **コピー**、**名前を付けて保存...**
- **エディターで開く**：この画像を注釈エディターで編集
- **実際のサイズ**：100% に戻す
- **閉じる**、**すべてのピン留めを閉じる**

トレイメニューの **すべてのピン留めを閉じる** で、すべてのピンを一度に閉じられます。
