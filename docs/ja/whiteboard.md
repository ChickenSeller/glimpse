# スクリーンホワイトボード

スクリーンペンは、説明、プレゼンテーション、画面共有の最中に画面へ直接書き込むための機能です。

![スクリーンペン](/images/ja/whiteboard.png)

## 開く・閉じる

ツールバーの **ペン** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>2</kbd> を押します。ポインターのある画面全体が描画面になり、上部にツールバーが表示されます。<kbd>Esc</kbd> を押すか **閉じる** をクリックすると終了します。

スクリーンペンのツールバーはキャプチャや画面共有には映らず、見ている人には描いた内容だけが見えます。

## 背景

ツールバーの **背景** で選びます。

| 背景 | 説明 |
| --- | --- |
| ライブの画面 | 実際の画面に描き、下の内容は引き続き更新される（既定） |
| 静止した画面 | 開いた時点の画面の画像に描く |
| ホワイトボード | 白い背景に描く |

## クリックスルー

**クリックスルー** をオンにすると、描いた内容を残したまま、マウスで下のプログラムを操作できます。スクリーンペンを開いている間にもう一度 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>2</kbd> を押すと、描画とプログラムの操作を切り替えます。

## ツールとショートカット

| ツール | キー | 説明 |
| --- | --- | --- |
| ペン | <kbd>P</kbd> | 自由な線 |
| 蛍光ペン | <kbd>H</kbd> | 半透明の太い線 |
| 直線 | <kbd>L</kbd> | <kbd>Shift</kbd>：45° 単位 |
| 矢印 | <kbd>A</kbd> | <kbd>Shift</kbd>：45° 単位 |
| 四角形 | <kbd>R</kbd> | <kbd>Shift</kbd>：正方形 |
| 楕円 | <kbd>O</kbd> | <kbd>Shift</kbd>：正円 |
| 消しゴム | <kbd>E</kbd> | ひと筆ごと消す |
| 線の太さ | <kbd>[</kbd>、<kbd>]</kbd> | 細く、太く |

| 操作 | キー |
| --- | --- |
| 元に戻す、やり直し | <kbd>Ctrl</kbd>+<kbd>Z</kbd>、<kbd>Ctrl</kbd>+<kbd>Y</kbd> |
| すべて消去 | <kbd>Delete</kbd> |
| コピー（画面と描いた内容） | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| 名前を付けて保存 | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| 閉じる | <kbd>Esc</kbd> |

ツールバーでは 6 色から選べます。左端のハンドルをドラッグするとツールバーを移動できます。
