# はじめに

Glimpse は Windows と Linux 用のスクリーンショット・画面録画ツールです。キャプチャした画像には注釈を付けて保存・コピーしたり、画面に貼り付けたりできます。画像内の文字を認識してコピー・翻訳し、訳文を画像の元の位置に描き戻すこともできます。Glimpse は MIT ライセンスのオープンソースソフトウェアで、無料で使用できます。

Glimpse は小さなツールバーと通知領域（トレイ）に常駐し、すべての機能をグローバルホットキーで呼び出せます。

## 主な機能

| 機能 | 説明 | 参照 |
| --- | --- | --- |
| キャプチャ | ウィンドウやコントロール、矩形、フリーハンド領域、全画面。遅延も可能 | [画面のキャプチャ](./capture) |
| スクロールキャプチャ | 長いページや文書を自動でスクロールしてつなげる（Windows、試験的） | [スクロールキャプチャ](./scrolling) |
| 注釈と編集 | 矢印、図形、テキスト、番号、ハイライト、ぼかし、トリミング、回転、サイズ変更 | [プレビューとエディター](./editor) |
| ピン留め | キャプチャした領域を最前面に固定表示 | [画面に貼り付け](./pin) |
| 文字認識 | PaddleOCR、Windows OCR、Tesseract | [文字認識と翻訳](./ocr) |
| 翻訳 | オフラインの Firefox 翻訳とローカルモデル、Google、DeepL、Claude、OpenAI 互換 API などのオンラインサービス | [翻訳エンジンとプロンプト](./translation) |
| 画面録画 | MP4 に録画。マウスのクリックや押したキーも表示可能 | [画面録画](./record) |
| スクリーンペン | ライブの画面、静止した画面、ホワイトボードに描画 | [スクリーンホワイトボード](./whiteboard) |
| その他のツール | QR コードの読み取り、クロスヘアと色の取得、スクリーンルーラー | [QR コード、十字線、定規](./tools) |

## 動作環境

- Windows 10、Windows 11（x64）。
- Linux：`.deb` と `.rpm` パッケージを提供。Debian 12、Ubuntu 22.04、Fedora 35、RHEL 9 以降で、X11 と Wayland のどちらでも動作します。一部の機能は未対応です。[Linux](./linux) を参照してください。
- 表示言語：日本語、英語、簡体字中国語。

文字認識とオフライン翻訳のモデルはプログラムに含まれていません。初めて使うときに自動でダウンロードされ、以後はオフラインで使用できます。
