# スクロールキャプチャ

スクロールキャプチャは、長いウェブページ、チャットの履歴、長いリストなど、1 画面に収まらない内容をキャプチャします。Glimpse がスクロールしながらキャプチャし、各部分を 1 枚の縦長の画像につなげます。

::: warning 試験的な機能
スクロールキャプチャは現在 Windows のみの対応で、試験段階です。スクロールの仕方が特殊なプログラムでは、正しくつながらないことがあります。
:::

## 自動スクロール

1. ツールバーの **スクロール** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>9</kbd> を押します。
2. スクロールする範囲を選びます。
   - スクロールできるコントロール（ウェブページ、文書、リストなど）にポインターを合わせてクリックする、または
   - 矩形をドラッグし、その中のスクロールする位置をクリックします。
3. Glimpse が下方向へ自動でスクロールしてつなげていきます。範囲の上に、つなげた高さが表示されます。
4. 内容の最後まで来ると自動で終了します。途中で止めるには <kbd>Esc</kbd> を押すか **停止** をクリックします。

つなげた画像はプレビューウィンドウに表示され、保存、コピー、編集を行えます。[プレビューとエディター](./editor)を参照してください。

## 手動スクロール

- 自動スクロール中にマウスホイールを回すと、手動スクロールに切り替わります。
- 範囲を選ぶときに <kbd>Ctrl</kbd> を押していると、最初から手動でスクロールします。

手動の場合は、キャプチャしたい内容を範囲内に順にスクロールしていけば、Glimpse がつなげます。一度にスクロールしすぎてつながらないときは「つながりません：少し戻してください」と表示されます。

## 最後の部分を取り消す

最後につなげた部分が正しくない場合は、**元に戻す** をクリックするか <kbd>Ctrl</kbd>+<kbd>Z</kbd> を押し、その部分をスクロールし直します。

## プレビュー

既定では、範囲の横（空きがある場合）にそれまでつなげた画像が表示され、ずれにすぐ気付けます。**設定 > 全般** で **スクロールキャプチャ中にプレビューを表示** をオフにしたり、不透明度を変更したりできます。

## 管理者として実行されているウィンドウ

Windows では、通常のプログラムから管理者として実行されているウィンドウをスクロールできません。このようなウィンドウでは、Glimpse が次の選択肢を表示します。

- **管理者として再起動**：Glimpse を管理者として再起動し、自動スクロールできるようにします。
- **自分でスクロール**：ホイールを自分で回します。Glimpse は通常どおりつなげます。
