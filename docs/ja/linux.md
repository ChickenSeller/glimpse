# Linux

Glimpse は `.deb` と `.rpm` パッケージを提供しています。インストール方法は[ダウンロードとインストール](./install#linux)を参照してください。

## 機能の違い

| 機能 | Windows | X11 | Wayland |
| --- | --- | --- | --- |
| 矩形、フリーハンド、全画面のキャプチャ | ✓ | ✓ | ✓ |
| ウィンドウの選択、ポインターのキャプチャ | ✓ | 予定 | — |
| スクロールキャプチャ | ✓ | 予定 | 予定 |
| グローバルホットキー | ✓ | GNOME | GNOME |
| 録画でのクリックとキーの表示 | ✓ | 予定 | — |
| PaddleOCR、Tesseract | ✓ | ✓ | ✓ |
| Windows OCR | ✓ | — | — |
| ローカルモデルによる翻訳 | ✓ | ✓ | ✓ |
| Firefox 翻訳 | ✓ | 予定 | 予定 |
| アプリ内での更新 | ✓ | 新バージョンを通知 | 新バージョンを通知 |

利用できない機能は、画面上で灰色表示になります。

## GNOME でのホットキー

GNOME では、Glimpse のホットキーは GNOME の設定のカスタムキーボードショートカットとして登録されます。Glimpse が起動していないときに押しても、Glimpse が起動して対応する機能を実行します。その他のデスクトップ環境ではグローバルホットキーは未対応のため、ツールバーかトレイメニューを使ってください。

## Wayland

- Wayland のウィンドウは自分の位置を決めたり最前面に留まったりできないため、Wayland セッションでは Glimpse は XWayland 経由で動作します（環境変数 `QT_QPA_PLATFORM` を設定した場合を除く）。
- スクリーンショットはデスクトップポータル（xdg-desktop-portal）経由で撮影します。初回のキャプチャで許可を求められるので、一度だけ許可してください。拒否した場合は、Glimpse が **もう一度確認** を表示します。
- スクリーンショットにポインターは含められません。録画ではポインターが表示されます。
