# クイックスタート

## 1. ダウンロードと起動

[リリースページ](https://pages.yanlei.org/kaguya/glimpse/releases.html)から最新の Windows 用アーカイブ（`Glimpse-<バージョン>-windows-x64.zip`）をダウンロードし、任意のフォルダーに展開して `glimpse.exe` を実行します。インストールも管理者権限も不要です。

起動すると画面に Glimpse のツールバーが表示され、通知領域（トレイ）に Glimpse のアイコンが表示されます。

![ツールバー](/images/ja/toolbar.png)

## 2. キャプチャする

1. ツールバーの **ウィンドウ** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd> を押します。
2. キャプチャするウィンドウにポインターを合わせてクリックします。または、ドラッグして矩形を選択します。
3. キャプチャした画像がプレビューウィンドウに表示されます。ここで **名前を付けて保存**、**コピー**、**編集**（矢印やテキストなどの注釈）、**画面にピン留め** を行えます。

詳しくは[画面のキャプチャ](./capture)と[プレビューとエディター](./editor)を参照してください。

## 3. 文字を認識して翻訳する

1. ツールバーの **テキスト** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>5</kbd> を押します。
2. 文字を含む範囲をドラッグします。初回は認識モデル（約 31 MB）をダウンロードするか確認されます。
3. 認識した文字が **文字認識・翻訳** ウィンドウに表示されます。必要に応じて修正し、**コピー** をクリックします。
4. 翻訳先の言語を選び、**翻訳** をクリックします。既定ではオフラインの Firefox 翻訳を使用し、言語の組み合わせごとに初回だけ言語ファイルをダウンロードします。
5. **翻訳画像** をクリックすると、元の文字の位置に訳文を描いた画像が作成されます。

![文字認識・翻訳ウィンドウ](/images/ja/ocr.png)

翻訳エンジンの選び方は[翻訳エンジンとプロンプト](./translation)を参照してください。

## 4. よく使うホットキー

| ホットキー | 機能 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd> | ウィンドウ／領域をキャプチャ |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>3</kbd> | 全画面をキャプチャ |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | 画面にピン留め |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>5</kbd> | 文字認識・翻訳 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> | 画面を録画（もう一度押すと停止） |

すべてのホットキーは[ツールバー、トレイ、ショートカットキー](./toolbar#ホットキー)にあります。
