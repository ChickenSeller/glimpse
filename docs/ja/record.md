# 画面録画

Glimpse は画面上のウィンドウや領域を MP4 動画に録画します。操作手順の説明や不具合の報告に便利です。音声は録音しません。

## 開始と停止

1. ツールバーの **録画** をクリックするか、<kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> を押します。
2. 録画するウィンドウをクリックするか、範囲をドラッグします。[キャプチャ前の遅延](./capture#遅延キャプチャ)を設定している場合は、先にカウントダウンします。
3. 録画が始まり、録画パネルが表示されます。**一時停止**、再開、**録画を停止** を行えます。
4. もう一度 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> を押すか、ツールバーの **録画** をクリックしても停止します。

録画は、設定で選んだフォルダーの `Recordings` サブフォルダーに保存されます。停止すると **録画完了** ウィンドウに長さとファイルサイズが表示されます。

| ボタン | 動作 |
| --- | --- |
| 開く | システムのプレーヤーで再生 |
| フォルダーを開く | ファイルマネージャーで表示 |
| パスをコピー | 録画ファイルのパスをクリップボードにコピー |
| 破棄 | 録画をごみ箱に移動 |

## マウスとキーの表示

**設定 > 録画** の項目：

| 設定 | 説明 |
| --- | --- |
| マウスポインターを強調表示 | ポインターを見つけやすくする |
| マウスクリックを表示 | クリックした位置を動画に示す |
| 押したキーを表示 | 押したキーを動画に表示 |
| 表示方法 | **キー名**（`Ctrl + S` など）、**キーボード全体**（画面上のキーボードで押したキーが光る）、**キーボードとキー名** |
| 位置 | 画面内の上・下・左・右、または画面外の一方 |

画面外に置くと、動画のその側にキー表示用の帯が加わり、画面を隠しません。その分、動画のサイズが大きくなります。

::: warning
キーを表示すると、パスワードを含め、入力した内容がすべて動画に映ります。
:::

これらの機能は現在 Windows のみで利用できます。

## 画質

| 設定 | 説明 |
| --- | --- |
| ビデオのフレームレート | 15、24、30（既定）、60 fps |
| 色の精細さ | **標準**：一般的な動画と同様に 2×2 ピクセルごとに 1 色で、細い色付きの線がにじみます。**高**：ピクセルごとの色を保持し、グラフやコードのハイライトに向きます。ファイルは約 3 倍になります |

幅または高さが 2048 ピクセルを超える範囲は H.265 で保存され、再生できないプレーヤーもあります。
