# 截图

## 窗口和区域

单击工具栏上的 **窗口**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd>。屏幕会冻结，然后：

- **截取窗口或控件**：将鼠标移到窗口上，Glimpse 用边框标出鼠标下的窗口，并显示它的标题、程序名和尺寸。单击即可截取。滚动鼠标滚轮可在外层窗口和其中的控件（按钮、面板等）之间切换。
- **截取矩形区域**：按住鼠标左键拖出矩形，松开即截取。拖动时按住 <kbd>Space</kbd> 可移动整个矩形。

![选择窗口](/images/capture-window.png)

光标旁实时显示所在像素的坐标和矩形的尺寸，便于精确对齐。

按 <kbd>Esc</kbd> 或单击鼠标右键取消。

::: info Linux
在 Linux 上不能选择窗口，只能拖出矩形。参见 [Linux](./linux)。
:::

### 截取前调整选区

在 **设置 > 常规** 中勾选 **选好区域后先调整再截取** 后，拖出矩形不会立即截取，而是先进入调整状态：

![调整选区](/images/capture.png)

| 操作 | 作用 |
| --- | --- |
| 拖动边框或手柄 | 移动选区或调整大小 |
| 方向键 | 移动 1 像素；按住 <kbd>Shift</kbd> 移动 10 像素 |
| <kbd>Ctrl</kbd>+方向键 | 调整大小 |
| <kbd>Enter</kbd> 或在选区内双击 | 截取 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 复制选区内容到剪贴板，然后结束 |
| 右键 | 放弃此选区，重新选择 |

此设置也适用于贴图、文字识别和二维码识别。

## 手绘区域

单击工具栏上的 **手绘**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>6</kbd>，然后按住鼠标沿要截取的部分画一圈，松开即截取。

轮廓以外的部分默认是透明的（保存为 PNG 时保留透明）。也可以在 **设置 > 常规** 的 **手绘区域外部** 中取消 **透明**，改为填充指定的颜色。

## 全屏

按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>3</kbd> 截取整个屏幕。有多个显示器时，截取所有显示器组成的整个桌面。

工具栏上的 **捕捉全屏** 按钮默认隐藏，可在 **设置 > 工具栏** 中显示。

## 延时截图

需要截取菜单、提示框等鼠标一动就会消失的内容时，可以延时截图：

1. 单击工具栏上的 **截图前延迟** 按钮，选择 1、2、3、5、10 秒或 **自定义...**。
2. 开始截图。屏幕上显示倒计时，这时打开要截取的菜单。
3. 倒计时结束后，屏幕冻结，再选择区域。

倒计时期间单击或按 <kbd>Esc</kbd> 可取消。延迟设置会一直保留，不需要时请选择 **不延迟**。

## 截图之后

截取的图片显示在预览窗口中，可以保存、复制、编辑、贴到屏幕或识别文字，参见[预览与编辑](./editor)。

如在 **设置 > 常规** 中勾选 **截图后自动复制到剪贴板**，每次截图都会同时复制到剪贴板。

## 截图相关设置

**设置 > 常规 > 截图** 中：

| 设置 | 说明 |
| --- | --- |
| 截入 Glimpse 工具条 | 截图时不隐藏 Glimpse 的工具栏 |
| 截入鼠标指针 | 在截图中保留鼠标指针（仅 Windows） |
| 截图后自动复制到剪贴板 | 每次截图都复制到剪贴板 |
| 手绘区域外部 | 透明，或填充指定颜色 |
| 选好区域后先调整再截取 | 参见[截取前调整选区](#截取前调整选区) |
