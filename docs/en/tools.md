# QR Codes, Crosshair and Ruler

## QR codes

Click **QR Code** on the toolbar, or press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>4</kbd>, and select the area with the QR code or barcode. No phone needed.

The **Scan QR Code** window lists every code found and its type. Select one to **Copy** its content, or, for a web address, **Open Link**.

## Crosshair and color picker

Click **Crosshair** on the toolbar, or press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>8</kbd>. A crosshair spans the screen, and a magnifier beside it shows the pixel under the pointer, its color (HEX and RGB) and position.

![The crosshair](/images/en/crosshair.png)

### Measuring

Click to lock a point, then move the pointer: the panel shows the horizontal, vertical and straight distance between the two, and a line joins them on the screen. Right-click to unlock.

### Picking a color

Double-click a pixel to open the **Screen Color** window, which copies the color as HEX, RGB or HSL; **Pick Again** goes back to the crosshair.

![Screen Color](/images/en/color.png)

### Keys

| Key | Action |
| --- | --- |
| Arrow keys | Move the crosshair by 1 pixel |
| <kbd>Space</kbd> | Lock here |
| <kbd>Enter</kbd> | Pick this pixel's color |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the position |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copy the color |
| <kbd>Esc</kbd> | Exit |

## Screen ruler

Click **Ruler** on the toolbar, or press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>7</kbd>. A horizontal and a vertical ruler appear in a cross, see-through and on top, showing in pixels how far the pointer is from the cross along each.

| Action | Effect |
| --- | --- |
| Drag the ruler | Move it |
| Drag an end | Change that arm's length |
| Arrow keys | Move it |
| <kbd>Ctrl</kbd>+arrow keys | Change the length |
| <kbd>Ctrl</kbd>+wheel | Change the opacity |
| Hold <kbd>Ctrl</kbd> | Show the angle between the x- and y-axis and the line from the cross to the pointer |

The context menu shows angles in **Degrees** or **Radians**, or **Close**s the ruler. Its position and length are kept for next time.
