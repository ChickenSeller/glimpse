# Screen Whiteboard

The screen whiteboard is for marking up the screen while explaining, presenting or sharing it.

![The screen whiteboard](/images/en/whiteboard.png)

## Opening and closing

Click **Whiteboard** on the toolbar, or press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>2</kbd>. The whiteboard covers the screen under the pointer, with its toolbar at the top. Press <kbd>Esc</kbd> or click **Close** to leave.

The whiteboard's toolbar stays out of captures and screen sharing: viewers see the drawing only.

## Background

Choose with **Background** on the toolbar:

| Background | Description |
| --- | --- |
| Live Screen | Draw over the live screen, which goes on updating underneath (default) |
| Frozen Screen | Draw over a picture of the screen as it was when the whiteboard opened |
| Whiteboard | Draw on plain white |

## Pass-through

With **Pass-Through** on, the mouse works the programs below and the drawing stays. While the whiteboard is open, <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>2</kbd> switches between drawing and working the programs.

## Tools and shortcuts

| Tool | Key | Description |
| --- | --- | --- |
| Pen | <kbd>P</kbd> | Freehand lines |
| Highlighter | <kbd>H</kbd> | Wide see-through lines |
| Line | <kbd>L</kbd> | <kbd>Shift</kbd>: in 45° steps |
| Arrow | <kbd>A</kbd> | <kbd>Shift</kbd>: in 45° steps |
| Rectangle | <kbd>R</kbd> | <kbd>Shift</kbd>: square |
| Ellipse | <kbd>O</kbd> | <kbd>Shift</kbd>: circle |
| Eraser | <kbd>E</kbd> | Removes whole strokes |
| Line width | <kbd>[</kbd>, <kbd>]</kbd> | Thinner, thicker |

| Action | Key |
| --- | --- |
| Undo, redo | <kbd>Ctrl</kbd>+<kbd>Z</kbd>, <kbd>Ctrl</kbd>+<kbd>Y</kbd> |
| Clear | <kbd>Delete</kbd> |
| Copy (the screen with the drawing) | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| Save As | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| Close | <kbd>Esc</kbd> |

The toolbar also has six colors. Drag the handle at its left end to move it.
