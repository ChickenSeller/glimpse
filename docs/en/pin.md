# Pinning to the Screen

A pin keeps a captured area in a small window on top of all others: handy for keeping reference material in view, noting a number for a moment or comparing two versions.

![A pin](/images/en/pin.png)

## Pinning

- Click **Pin** on the toolbar, or press <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd>, and select an area. The pin appears right where it was taken, as if that part of the screen had frozen.
- In the preview window, click **Pin to Screen** (<kbd>Ctrl</kbd>+<kbd>P</kbd>) to pin a capture.

Any number of pins can be open at once.

## Working with pins

| Action | Effect |
| --- | --- |
| Drag | Move the pin |
| Mouse wheel | Zoom around the pointer |
| <kbd>Ctrl</kbd>+wheel | Change the opacity |
| Double-click, or the close button at the top right | Close the pin |

When the pointer enters a pin, these are shown briefly.

The context menu has:

- **Copy** and **Save As...**
- **Open in Editor**: edit the pin's image in the annotation editor
- **Actual Size**: back to 100%
- **Close** and **Close All Pins**

**Close All Pins** in the tray menu closes all pins at once.
