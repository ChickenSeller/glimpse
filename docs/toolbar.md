# 工具栏、托盘与快捷键

## 工具栏

![工具栏](/images/toolbar.png)

工具栏从左到右的按钮依次为：

| 按钮 | 功能 | 参见 |
| --- | --- | --- |
| 拖动手柄 | 按住拖动工具栏 | |
| 窗口 | 单击窗口或控件，或拖出矩形截图 | [截图](./capture) |
| 滚动 | 滚动截图（Windows，实验性） | [滚动截图](./scrolling) |
| 手绘 | 沿任意轮廓截图 | [截图](./capture#手绘区域) |
| 贴图 | 截取区域并贴到屏幕上 | [贴图](./pin) |
| 录屏 | 录制屏幕，再按一次停止 | [录屏](./record) |
| 二维码 | 识别区域中的二维码和条形码 | [二维码](./tools#二维码) |
| 文字 | 识别区域中的文字，可复制或翻译 | [文字识别与翻译](./ocr) |
| 十字线 | 全屏十字线，显示位置、颜色和距离 | [十字线与取色](./tools#十字线与取色) |
| 标尺 | 以像素测量的屏幕标尺 | [屏幕标尺](./tools#屏幕标尺) |
| 白板 | 在屏幕上画 | [屏幕白板](./whiteboard) |
| 截图前延迟 | 设置截图前等待的秒数 | [截图](./capture#延时截图) |
| 打开 | 打开图片进行编辑 | [预览与编辑](./editor#打开已有图片) |
| 设置 | 打开设置窗口 | [设置](./settings) |
| 最小化到托盘 | 隐藏工具栏，可从托盘图标或快捷键再次调出 | |

“捕捉全屏”按钮默认隐藏，可在设置中显示。

### 停靠在屏幕边缘

把工具栏拖到屏幕边缘松开，工具栏会停靠在该边缘，平时缩成一条窄边，鼠标移上去时展开。拖离边缘即可取消停靠。

### 打开图片

把图片文件拖放到工具栏上，即可在编辑器中打开。

### 自定义

在 **设置 > 工具栏** 中：

- 取消勾选可隐藏按钮；拖动列表项或使用 **上移**、**下移** 调整顺序。
- **工具栏大小** 可调整按钮的大小。

## 托盘图标

单击通知区域中的 Glimpse 图标可显示工具栏。右键菜单包含各项截图功能，以及：

- **打开图片...**
- **关闭所有贴图**
- **显示工具栏**
- **设置...**
- **关于 Glimpse...**
- **退出**

## 快捷键

快捷键在任何程序中都可使用（全局快捷键）。

| 快捷键 | 功能 |
| --- | --- |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>1</kbd> | 捕捉窗口/区域 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>2</kbd> | 屏幕白板（白板打开时：切换鼠标穿透） |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>3</kbd> | 捕捉全屏 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd> | 贴图到屏幕 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>4</kbd> | 识别二维码 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>5</kbd> | 文字识别和翻译 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>6</kbd> | 捕捉手绘区域 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>7</kbd> | 屏幕标尺 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>8</kbd> | 十字线/取色 |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>9</kbd> | 滚动截图（实验性） |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd> | 录制屏幕（再按一次停止） |

### 修改快捷键

1. 打开 **设置 > 快捷键**。
2. 单击某一项的输入框，按下新的组合键。清空输入框即可禁用该快捷键。
3. 单击 **确定**。

设置窗口打开期间，快捷键暂停生效。

如某个快捷键已被其他程序占用，Glimpse 启动时会在托盘弹出提示，设置中该项也会标出“已被其他程序占用”，请换一个组合键。
