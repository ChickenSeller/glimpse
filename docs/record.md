# 录屏

Glimpse 把屏幕上的一个窗口或区域录制为 MP4 视频，适合制作操作演示和问题反馈。可同时录制麦克风和电脑播放的声音。

## 开始和停止

1. 单击工具栏上的 **录屏**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd>。
2. 单击要录制的窗口，或拖出要录制的区域。如设置了[截图前延迟](./capture#延时截图)，会先倒计时。
3. 录制开始，屏幕上出现录屏面板，可 **暂停**、**继续** 或 **停止录制**。
4. 再按一次 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>V</kbd>，或单击工具栏上的 **录屏**，也可停止录制。

录像保存在设置中所选文件夹下的 `Recordings` 子文件夹。停止后弹出 **录制完成** 窗口，显示时长和文件大小：

| 按钮 | 作用 |
| --- | --- |
| 打开 | 用系统的播放器打开录像 |
| 打开所在文件夹 | 在文件管理器中显示录像 |
| 复制路径 | 把录像文件的路径复制到剪贴板 |
| 废弃 | 把录像移到回收站 |

## 声音

默认不录制声音。在 **设置 > 录屏 > 声音** 中：

| 设置 | 说明 |
| --- | --- |
| 录制麦克风 | 录制所选的输入设备。**默认设备** 跟随系统的默认麦克风 |
| 录制电脑播放的声音 | 录制默认输出设备正在播放的声音，如视频、提示音 |

两者都选时，声音混合为一条音轨，以 AAC 编码保存在 MP4 中。暂停期间不录制声音，与画面保持同步。

麦克风无法打开时，录屏不会开始，并提示原因。在 Windows 上，请确认 **设置 > 隐私和安全性 > 麦克风** 中允许桌面应用使用麦克风。

在 Linux 上，录制电脑播放的声音需要 PipeWire。

## 在视频中显示鼠标和按键

在 **设置 > 录屏** 中：

| 设置 | 说明 |
| --- | --- |
| 高亮鼠标指针 | 突出显示指针，便于观众找到它 |
| 显示鼠标点击 | 在视频中标出每次点击 |
| 显示按下的按键 | 在视频中显示按下的按键 |
| 显示方式 | **按键文字**（如 `Ctrl + S`）、**完整键盘**（屏幕键盘上亮起按下的键）或 **键盘和文字** |
| 位置 | 显示在画面内的上、下、左、右，或画面外的一侧 |

放在画面外时，视频会在那一侧加一条边带来显示按键，不遮挡画面，视频尺寸也相应变大。

::: warning
显示按键时，输入的所有内容都会出现在视频中，包括密码。
:::

以上功能目前仅 Windows 提供。

## 画质

| 设置 | 说明 |
| --- | --- |
| 视频帧率 | 15、24、30（默认）或 60 帧/秒 |
| 颜色细节 | **标准**：普通视频的做法，每 2×2 个像素共用一种颜色，细的彩色线条会变模糊。**高**：保留每个像素的颜色，适合图表和代码高亮，文件约为标准的三倍 |

宽或高超过 2048 像素的区域会保存为 H.265 编码，部分播放器可能无法播放。
