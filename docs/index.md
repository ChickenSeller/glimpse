# 简介

Glimpse 是一款截图与录屏工具，支持 Windows 和 Linux。截下的图可以标注、保存、复制或贴在屏幕上；截图中的文字可以识别出来，复制或翻译，也可以把译文直接画回图片上。Glimpse 以 MIT 许可证开源，免费使用。

Glimpse 常驻在一个小工具栏和通知区域（托盘）中，所有功能都可以用全局快捷键调用。

![截图时选择区域](/images/capture.png)

## 主要功能

| 功能 | 说明 | 参见 |
| --- | --- | --- |
| 截图 | 窗口或控件、矩形、手绘区域、全屏，可延时 | [截图](./capture) |
| 滚动截图 | 自动滚动并拼接长网页或长文档（Windows，实验性） | [滚动截图](./scrolling) |
| 标注与编辑 | 箭头、形状、文字、编号、高亮、模糊，以及裁剪、旋转、调整大小 | [预览与编辑](./editor) |
| 贴图 | 把截取的区域固定在屏幕最上层 | [贴图](./pin) |
| 文字识别 | PaddleOCR、Windows OCR、Tesseract | [文字识别与翻译](./ocr) |
| 翻译 | 离线的 Firefox 翻译和本地大模型，以及 Google、DeepL、Claude、OpenAI 兼容接口等在线服务 | [翻译引擎与提示词](./translation) |
| 录屏 | 录制为 MP4，可显示鼠标点击和按键 | [录屏](./record) |
| 屏幕白板 | 在实时屏幕、冻结的屏幕或白板上画 | [屏幕白板](./whiteboard) |
| 其他工具 | 二维码识别、十字线与取色、屏幕标尺 | [二维码、十字线与标尺](./tools) |

## 系统要求

- Windows 10、Windows 11（x64）。
- Linux：提供 `.deb` 和 `.rpm` 安装包，支持 Debian 12、Ubuntu 22.04、Fedora 35、RHEL 9 及更高版本，X11 和 Wayland 均可使用。部分功能暂不支持，参见 [Linux](./linux)。
- 界面语言：简体中文、日语、英语。

文字识别和离线翻译所需的模型不随程序附带，首次使用时自动下载，之后可离线使用。
