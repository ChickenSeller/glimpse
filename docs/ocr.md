# 文字识别与翻译

## 识别文字

1. 单击工具栏上的 **文字**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>5</kbd>，然后选择包含文字的区域。也可以在预览窗口中单击 **文字识别和翻译...**。
2. 打开 **文字识别和翻译** 窗口，上方显示截取的图片，识别出的每行文字都用方框标出。
3. 识别出的文字显示在中间的文本框中，每个段落占一行。可以直接修改，然后单击 **复制**。

![文字识别和翻译窗口](/images/ocr.png)

**识别引擎** 下拉框可以为本窗口换用其他引擎重新识别；打开窗口时使用的引擎在 **设置 > 文字识别** 中设定。

## 翻译

1. 在 **翻译为** 中选择目标语言。原文的语言自动判断。
2. 在 **引擎** 中选择翻译引擎或本地模型。打开窗口时使用的引擎在 **设置 > 翻译** 中设定。
3. 单击 **翻译**。译文显示在下方，可以修改后单击 **复制译文**。

修改识别出的文字后再翻译，译文会沿用修改后的分行和空行。

使用大语言模型类的引擎（Claude、OpenAI 兼容接口、本地通用模型）时，会出现 **提示词** 按钮，可以为本窗口单独修改提示词，参见[翻译引擎与提示词](./translation#提示词)。

## 翻译图片

单击 **翻译图片**，Glimpse 把译文画在截图中原文的位置上，得到一张“翻译过的截图”，在预览窗口中打开，可以保存、复制或继续编辑。

<div class="compare">

![原图](/images/original.png)

![翻译图片](/images/translated.png)

</div>

Glimpse 会抹去原文、用周围的背景补上，再按原文的颜色、字号、粗细和对齐方式排入译文。纯色或渐变背景效果最好；有复杂纹理或照片的背景无法完全还原。

::: tip
翻译图片要求文本框中仍是“每个识别出的段落一行”。如果手动合并或拆分了段落，Glimpse 会提示先恢复分行再重新翻译。
:::

## 识别引擎

| 引擎 | 特点 | 首次使用 |
| --- | --- | --- |
| PaddleOCR（默认） | 识别最准确，尤其是中文和日文；一个模型即可识别所有支持的语言 | 下载约 31 MB 的模型 |
| Windows OCR | Windows 自带，无需下载；一次只能识别一种语言 | 需在 Windows 中安装该语言的“光学字符识别”功能 |
| Tesseract | 经典的开源引擎 | 每种语言下载 2–4 MB |

Windows OCR 使用所选语言中第一个已安装 OCR 组件的语言。如提示没有可用的语言，请在 Windows **设置 > 时间和语言 > 语言** 中添加该语言，并安装其“光学字符识别”功能。

### 识别语言

在 **设置 > 文字识别** 中勾选要识别的语言（文字）：简体中文、繁体中文、英语、日语、法语。选择的语言越少，识别越快、越准确。

![文字识别设置](/images/settings-ocr.png)

## 下载模型

识别模型和离线翻译的语言文件不随程序附带，首次需要时，Glimpse 会列出要下载的文件并询问是否下载。下载完成后即可离线使用。

下载较慢时：

- **复制原始链接** 或 **复制镜像链接**，用浏览器或下载工具下载，再单击 **选择文件...** 选中下载好的文件（可一次选择多个，Glimpse 按文件名对应）。
- 在 **设置 > 常规 > 下载** 中调整下载来源，参见[设置](./settings#下载)。

下载中途可以取消，回到这个窗口改用其他方式。
