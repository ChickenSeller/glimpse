# 二维码、十字线与标尺

## 二维码

单击工具栏上的 **二维码**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>4</kbd>，框选包含二维码或条形码的区域。不需要手机。

**识别二维码** 窗口列出找到的所有码及其类型。选中一项后，可以 **复制** 内容；内容是网址时，可以 **打开链接**。

## 十字线与取色

单击工具栏上的 **十字线**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>8</kbd>。屏幕上显示贯穿全屏的十字线，旁边的放大镜显示鼠标下像素的颜色（HEX 和 RGB）和坐标。

![十字线](/images/crosshair.png)

### 测量距离

单击锁定一个点，再移动鼠标，信息框中显示两点的水平、垂直距离和直线距离，屏幕上也会画出连线。右键解除锁定。

### 取色

双击要取色的像素，打开 **屏幕取色** 窗口，可分别复制 HEX、RGB 和 HSL 格式的颜色值，或单击 **重新取色**。

![屏幕取色](/images/color.png)

### 键盘操作

| 按键 | 作用 |
| --- | --- |
| 方向键 | 把十字线移动 1 像素 |
| <kbd>Space</kbd> | 锁定到当前位置 |
| <kbd>Enter</kbd> | 取当前像素的颜色 |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | 复制当前位置的坐标 |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | 复制当前像素的颜色 |
| <kbd>Esc</kbd> | 退出 |

## 屏幕标尺

单击工具栏上的 **标尺**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>7</kbd>。屏幕上出现一横一竖两把交叉的标尺，半透明并置于最上层，以像素显示鼠标沿各方向到交叉点的距离。

| 操作 | 作用 |
| --- | --- |
| 拖动标尺 | 移动标尺 |
| 拖动标尺的一端 | 改变该方向的长度 |
| 方向键 | 移动标尺 |
| <kbd>Ctrl</kbd>+方向键 | 改变长度 |
| <kbd>Ctrl</kbd>+滚轮 | 调整不透明度 |
| 按住 <kbd>Ctrl</kbd> | 显示鼠标与交叉点连线和 X 轴、Y 轴的夹角 |

右键菜单中可选择角度以 **角度制** 或 **弧度制** 显示，或 **关闭** 标尺。标尺的位置和长度会保存下来，下次打开时保持不变。
