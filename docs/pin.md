# 贴图

贴图把截取的区域作为一个小窗口固定在所有窗口之上，适合对照资料、临时记下数字或比较前后两个版本。

![贴图](/images/pin.png)

## 创建贴图

- 单击工具栏上的 **贴图**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>P</kbd>，然后选择区域。贴图出现在截取的原位置，看起来就像屏幕被“冻结”了一块。
- 在预览窗口中单击 **贴到屏幕**（<kbd>Ctrl</kbd>+<kbd>P</kbd>），把已截取的图片贴到屏幕上。

可以同时贴多张图。

## 操作

| 操作 | 作用 |
| --- | --- |
| 拖动 | 移动贴图 |
| 滚动鼠标滚轮 | 以鼠标位置为中心缩放 |
| <kbd>Ctrl</kbd>+滚轮 | 调整不透明度 |
| 双击，或单击右上角的关闭按钮 | 关闭这张贴图 |

鼠标移到贴图上时，会短暂显示操作提示。

右键菜单：

- **复制**、**另存为...**
- **在编辑器中打开**：在标注编辑器中编辑这张图
- **实际大小**：恢复为 100% 大小
- **关闭**、**关闭所有贴图**

托盘菜单中的 **关闭所有贴图** 可以一次关闭全部贴图。
