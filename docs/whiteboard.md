# 屏幕白板

屏幕白板用于讲解、演示或屏幕共享时在屏幕上直接圈画。

![屏幕白板](/images/whiteboard.png)

## 打开和关闭

单击工具栏上的 **白板**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>2</kbd>。白板覆盖鼠标所在的屏幕，顶部显示白板工具栏。按 <kbd>Esc</kbd> 或单击工具栏上的 **关闭** 退出。

白板工具栏不会出现在截图和屏幕共享中，观众只看到画的内容。

## 背景

单击工具栏上的 **背景** 选择：

| 背景 | 说明 |
| --- | --- |
| 实时屏幕 | 画在实时的屏幕上，下面的内容照常更新（默认） |
| 冻结屏幕 | 画在打开白板那一刻的屏幕画面上 |
| 白板 | 画在空白的白色背景上 |

## 鼠标穿透

开启 **鼠标穿透** 后，鼠标可以操作白板下面的程序，画的内容保留在屏幕上。白板打开时，再按一次 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>2</kbd> 即可在画画和操作程序之间切换。

## 工具和快捷键

| 工具 | 快捷键 | 说明 |
| --- | --- | --- |
| 画笔 | <kbd>P</kbd> | 自由画线 |
| 荧光笔 | <kbd>H</kbd> | 半透明的粗线 |
| 直线 | <kbd>L</kbd> | 按住 <kbd>Shift</kbd> 以 45° 为步长 |
| 箭头 | <kbd>A</kbd> | 按住 <kbd>Shift</kbd> 以 45° 为步长 |
| 矩形 | <kbd>R</kbd> | 按住 <kbd>Shift</kbd> 画正方形 |
| 椭圆 | <kbd>O</kbd> | 按住 <kbd>Shift</kbd> 画正圆 |
| 橡皮擦 | <kbd>E</kbd> | 整笔擦除 |
| 线宽 | <kbd>[</kbd>、<kbd>]</kbd> | 变细、变粗 |

| 操作 | 快捷键 |
| --- | --- |
| 撤销、重做 | <kbd>Ctrl</kbd>+<kbd>Z</kbd>、<kbd>Ctrl</kbd>+<kbd>Y</kbd> |
| 清空 | <kbd>Delete</kbd> |
| 复制（屏幕连同画的内容） | <kbd>Ctrl</kbd>+<kbd>C</kbd> |
| 另存为 | <kbd>Ctrl</kbd>+<kbd>S</kbd> |
| 关闭 | <kbd>Esc</kbd> |

工具栏上还有 6 种颜色可选。拖动工具栏左端的手柄可以移动工具栏。
