# 滚动截图

滚动截图可以截取超出一屏的内容，例如长网页、聊天记录或很长的列表：Glimpse 一边滚动一边截取，并把各部分拼接成一张长图。

::: warning 实验性功能
滚动截图目前仅支持 Windows，仍处于实验阶段。部分程序的滚动方式比较特殊，可能拼接不准确。
:::

## 自动滚动

1. 单击工具栏上的 **滚动**，或按 <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>9</kbd>。
2. 选择要滚动的区域：
   - 将鼠标移到可滚动的控件（网页内容、文档区域、列表等）上单击；或
   - 拖出一个矩形，然后在矩形内单击要滚动的位置。
3. Glimpse 开始自动向下滚动并拼接，选区上方显示已拼接的高度。
4. 滚动到底部时自动结束；也可以随时按 <kbd>Esc</kbd> 或单击 **停止**。

拼接好的长图显示在预览窗口中，可以保存、复制或编辑，参见[预览与编辑](./editor)。

## 手动滚动

- 自动滚动过程中转动鼠标滚轮，即可改为自己滚动。
- 选择区域时按住 <kbd>Ctrl</kbd>，从一开始就由自己滚动。

自己滚动时，只需把要截取的内容依次滚进选区，Glimpse 会自动拼接；滚得太快导致无法对齐时，选区上方会提示“未能对齐：请往回滚一点”。

## 撤回最后一段

如最后拼上的一段不正确，单击 **撤销** 或按 <kbd>Ctrl</kbd>+<kbd>Z</kbd>，然后重新滚动这一段。

## 拼接预览

默认在选区旁边（有空位时）显示已拼接的图像，出现错位时可以及时发现。在 **设置 > 常规** 中可以关闭 **滚动截图时显示预览**，或调整预览的不透明度。

## 以管理员身份运行的窗口

Windows 不允许普通程序向以管理员身份运行的窗口发送滚动操作。遇到这种窗口时，Glimpse 会提示：

- **以管理员身份重启**：以管理员身份重新启动 Glimpse，之后可以自动滚动；
- **自己滚动**：由你转动滚轮，Glimpse 照常拼接。
