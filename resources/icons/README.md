Icons are [Material Symbols](https://fonts.google.com/icons) (Outlined, weight 400, 24px)
by Google, licensed under the Apache License 2.0.

To add one: download its SVG from fonts.google.com/icons into this folder,
then list it in `../glimpse.qrc`. Icons are tinted to the palette at runtime,
so keep the SVG's default (black) fill.
